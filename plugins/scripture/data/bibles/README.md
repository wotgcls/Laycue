# Bundled Bible versions

- `kjv.xml`: the King James Version (1769), public domain. Text from https://github.com/aruljohn/Bible-kjv
  (one JSON file per book), written out as Zefania XML so it loads like any version an operator adds.

Operators add more versions in the panel (**Version → Add a version…**) from Zefania, OpenSong or Beblia XML
files. Only add versions you are allowed to use: most modern translations are copyrighted.
