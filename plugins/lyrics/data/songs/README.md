# Bundled songs

Hymns whose words are in the public domain everywhere (the authors died more than 70 years ago), so any church can
project them. They are loaded into the song library the first time Laycue Lyrics starts; after that the operator's
library (in OBS's plugin config folder) is what the panel uses, and these files are not read again.

Format: a `Title:` line, an `Author:` line, a blank line, then the song. A blank line starts a new part; a line such
as `Verse 1`, `Chorus` or `Bridge` names it.

Modern worship songs are copyrighted. Churches project them under a licence (CCLI in most countries) and type them
in, paste them, or import OpenLyrics files; Laycue does not download lyrics from the internet.
