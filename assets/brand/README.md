# Laycue brand

Source of truth: the owner's **Laycue Brand System** (v1.0, direction "2B Merge"), shared at
https://claude.ai/artifact/H435m1pPCfoLBUsLWPA1rj. A full-page capture is in
`laycue-brand-system.jpg`. The logo files here were rendered from its exact vector shapes.

## The mark

Four coloured bands (sources) enter from the left; the gaps close; one cream "screen" (the
output) leaves. Bands are always blue, green, amber, red, top to bottom.

| File | Use |
|---|---|
| `laycue-mark-on-dark.svg` | Mark on Ink or dark backgrounds (cream screen) |
| `laycue-mark-on-light.svg` | Mark on Cream or light backgrounds (ink screen) |
| `laycue-mark-mono-ink.svg`, `laycue-mark-mono-cream.svg` | One colour: print, embroidery, fax |
| `laycue-mark-square.svg` | Square crop for app icons (48 px and up) |
| `laycue-mark-16.svg`, `laycue-favicon-16.png` | Pixel-snapped 3-band version for 16 px |
| `laycue-lockup-on-dark.png`, `laycue-lockup-on-light.png` | Horizontal logo (mark + wordmark), 2× |
| `laycue-app-icon-dark-1024.png`, `laycue-app-icon-light-1024.png` | App icons |
| `laycue.ico` | Windows icon (16–256 px), used by the installer |

Wordmark: "laycue", lowercase, Archivo 800, width 108%, tracking −4.5%.

## Colour

| Name | Hex | Job |
|---|---|---|
| Ink | `#111110` | Page and panel base |
| Graphite | `#1C1B19` (raised), `#2C2A27` (lines) | Surfaces, dividers |
| Cream | `#F1EBDD` | Output, text, primary action |
| Signal Blue | `#2E8BFF` | Setup and edit |
| Cue Green | `#2FD18B` | Up next |
| Overlay Amber | `#FFB31A` | Overlays and notices |
| Tally Red | `#FF4D2E` | On air, only |

The four source colours appear together only as the bands. Alone, each has one job. They are
never used as text on Ink below 18 px.

## Type

- **Archivo** (variable width; SIL Open Font License): display 800, headings 700, UI 400–600.
- **JetBrains Mono** (SIL Open Font License): hotkeys, specs, eyebrows.
- Inside OBS the panel bundles Archivo and falls back to the system UI font.

## Controls (from the brand system)

8 px radius · 36 px default height, 44 px touch · press = 98% scale in 80 ms · spacing
4 / 8 / 14 / 24 · motion 120 ms ease-out, none with reduced motion. Go Live is the only filled
colour control (Tally Red); primary actions are Cream; setup actions are Signal Blue outlines.
